# 理解 CNN 如何工作

本文以项目的验证码识别模型为例，逐步讲解 CNN 的核心概念。

---

## 模型结构总览

```
输入图片（40×25 灰度图）
  → Conv2D(32, 3×3) → MaxPool → Dropout    ← 第1层卷积
  → Conv2D(64, 3×3) → MaxPool → Dropout    ← 第2层卷积
  → Conv2D(128, 3×3) → MaxPool → Dropout   ← 第3层卷积
  → Flatten(2560)
  → Dense(1024, relu) → Dropout             ← 第1个全连接
  → Dense(26)                               ← 第2个全连接（输出）
```

模型共 274 万参数，训练 880 步后验证集准确率达 99%。

---

## 卷积层：提取特征

### Q: 卷积核的形状 `[3, 3, 1, 32]` 是什么意思？

四个维度分别是 `[高, 宽, 输入通道数, 输出通道数]`。

- **3, 3** — 卷积核（滤波器）尺寸 3×3 像素，每次看图片的一个 3×3 小区域
- **1** — 输入通道数，灰度图只有 1 个通道（RGB 彩图是 3）
- **32** — 输出通道数，即 32 个不同的滤波器，每个学到不同的特征

类比：拿 32 个不同的 3×3 放大镜在图片上滑动扫描，每个放大镜关注不同的图案。

### Q: 卷积运算具体是怎么做的？

卷积就是加权求和。卷积核在图片上从左到右、从上到下滑动，每到一个位置就把核的权重和对应的像素值一一相乘，然后全部加起来得到一个数值。

```
第1层卷积核形状：3×3×1 = 9 个权重
在每个位置做：9 次乘法 → 1 次求和 → 加偏置 → ReLU → 1 个输出值

扫完整张 40×25 的图 → 产生 1 张 40×25 的特征图
32 个卷积核各扫一遍 → 产生 32 张特征图
```

### Q: 前向传播是什么？

前向传播就是数据从输入到输出依次流过每一层：

```
输入图片 → 卷积扫描 → 加偏置 → ReLU激活 → 池化缩小 → 下一层... → 输出26个分数
```

每一层的输出是下一层的输入，最终输出 26 个数值（对应 a-z），最大的那个位置就是预测的字母。

## 偏置：调节激活门槛

### Q: 偏置是干嘛的？

卷积扫描后的输出加一个常数，相当于 `y = wx + b` 里的 `b`。

每个通道有一个偏置值，加到该通道特征图的每一个像素上：

```
通道 1 的特征图         偏置 = 0.05
┌─────────────┐        ┌──────────────┐
│ 0.3  0.1    │         │ 0.35  0.15   │
│ 0.0  0.2    │ + 0.05= │ 0.05  0.25   │
└─────────────┘        └──────────────┘
每个像素都加同一个值
```

32 个通道就是 32 个不同的偏置值，每个通道加自己那个。

### Q: 为什么要加偏置？

偏置控制"多大的值才算激活"。配合 ReLU（负数变 0）来看：

- 偏置 b=0.5：原来 -0.3 变成 0.2，ReLU 后保留（弱信号通过了）
- 偏置 b=0：原来 -0.3 还是 -0.3，ReLU 后变 0（信号被丢弃）

**卷积核负责"看什么特征"，偏置负责"看到多强才算数"。**

初始值是随机小数（或全 0），训练过程中反向传播会自动调整每个通道的偏置到合适的值。

## ReLU：过滤信号

### Q: ReLU 激活函数就是删掉负数？

对，`ReLU(x) = max(0, x)`，负数变 0，正数不变。

可以理解为一个过滤器：在一堆信号里只保留有用的（正信号），丢弃无用的（负信号）。偏置是调节"什么算有用"的门槛。

### Q: 只有 ReLU 这一种激活函数吗？

还有多种：

| 激活函数 | 作用 | 使用场景 |
|---|---|---|
| **ReLU** | 负数变 0，正数不变 | CNN 主流，本项目使用 |
| **Sigmoid** | 压缩到 0~1 | 输出概率 |
| **Tanh** | 压缩到 -1~1 | 比 Sigmoid 收敛快 |
| **Leaky ReLU** | 负数保留一点 | 解决 ReLU 神经元死亡 |
| **GELU** | 平滑版 ReLU | Transformer / GPT 在用 |
| **Softmax** | 变成概率分布（加起来=1） | 多分类输出层 |

趋势：早期用 Sigmoid/Tanh，2012 年后 ReLU 成为主流，2018 年后 GELU 在 Transformer 里流行。

## 池化：精简特征

### Q: 池化是做什么的？

MaxPooling 在一个区域内只保留最大值，缩小特征图尺寸：

```
2×2 最大池化：

原始 4×4：             池化后 2×2：
┌──────────┐
│ 0.1  0.8 │ 0.3  0.2   ┌─────────┐
│ 0.3  0.5 │ 0.1  0.9   │ 0.8 0.9 │
├──────────┤             │ 0.7 0.6 │
│ 0.2  0.7 │ 0.4  0.1   └─────────┘
│ 0.6  0.4 │ 0.6  0.3
└──────────┘

每 2×2 区域取最大值，4个数变1个
```

作用：减少数据量、只保留最显著的信号、让模型对位置偏移不敏感。

## Dropout：防止死记硬背

### Q: Dropout 是做什么的？

训练时随机"关掉"一部分神经元（本项目丢弃 25%）：

```
保留 75%：
● ○ ● ●    →    ● _ ● ●    （○ 被随机关掉）
● ● ○ ●          ● ● _ ●
```

作用：防止模型死记硬背训练数据（过拟合），强制模型不依赖某几个特定神经元。只在训练时开启，推理时所有神经元都工作。

**池化让特征更精简，Dropout 让模型更健壮。**

## 多层卷积：从线条到字母

### Q: 为什么同样的卷积运算，第一层是"提取特征"，后面就变成"组合特征"了？

运算完全一样，区别在于**输入的含义**变了。

第1层输入是原始像素（灰度值），只能检测最基本的东西：

```
第1层 Conv(32)：检测横线、竖线、斜线、角点
```

第2层的输入不是原始图片，而是第1层输出的 32 张特征图。每个卷积核有 `3×3×32=288` 个权重，同时看 32 个通道，在同一个位置把所有通道的值乘以各自的权重然后**加成一个数**：

```
同一个位置，3×3 区域：

通道1（横线特征）：  通道2（竖线特征）：  通道3（斜线特征）：
  0.8  0.1  0.0      0.0  0.9  0.0      0.7  0.0  0.3
  0.2  0.9  0.1      0.1  0.8  0.1      0.0  0.6  0.1
  0.0  0.3  0.8      0.0  0.7  0.0      0.4  0.1  0.9

同一套权重对每个通道分别做卷积，然后所有通道的结果加在一起：
  权重 × 通道1 + 权重 × 通道2 + 权重 × 通道3 + ... + 权重 × 通道32 + 偏置
  ────────────   ────────────   ────────────         ───────────────
    横线的贡献     竖线的贡献     斜线的贡献            32个特征的综合
```

**"组合"就是加权求和。** 每个权重控制一个简单特征的重要性，加在一起判断是否构成某个复杂特征。

```
第2层 Conv(64)：把线条组合成弧线、交叉点、直角转弯
第3层 Conv(128)：把弧线和转弯组合成字母的局部形状
```

层层递进：

```
像素 → 线条 → 笔画 → 字母局部 → 完整字母 → 26 分类
```

### Q: 第2层运算结束后有多少个特征图？

输出通道数 = 卷积核个数，跟输入通道数无关：

```
卷积核1 扫描 32张图 → 各通道加权求和 → 1 张特征图
卷积核2 扫描 32张图 → 各通道加权求和 → 1 张特征图
...
卷积核64 扫描 32张图 → 各通道加权求和 → 1 张特征图

最终输出：64 张特征图
```

32 个输入通道不会变成 32×64 张。每个卷积核把所有输入通道在同一个位置的结果加成一个数，所以一个卷积核只输出 1 张特征图。

### Q: 第3层和第2层思路一样吗？

完全一样，只是通道数不同：

```
第2层：64 个卷积核，扫描 64 张特征图 → 输出 64 张
第3层：128 个卷积核，扫描 64 张特征图 → 输出 128 张
```

### Q: 通道数 32 怎么确定？跟 26 分类有关系吗？

跟 26 分类没有直接关系，是经验值。规律是**浅层少、深层多**：

- 浅层提取简单特征（线条），少量滤波器够用
- 深层组合复杂特征（笔画），需要更多滤波器

常见选择：简单任务 32→64→128，复杂任务（如 ImageNet）64→128→256→512→512。

## 全连接层：根据特征做分类

### Q: 全连接层是干嘛的？

卷积层负责"看图提取特征"，全连接层负责"根据特征做分类"。

卷积层最后输出 128 张 5×4 的特征图，先 Flatten 展平：

```
128 张 5×4 的特征图 → 展平成 2560 个数的一维数组
```

然后两层全连接做加权求和：

```
2560 个特征值
      ↓  Dense(1024)  加权求和
   1024 个中间值
      ↓  Dense(26)    加权求和
   26 个得分：[a=0.1, b=0.05, ..., e=2.8, ..., z=0.3]
                                         ↑
                                      最大值 → 预测 'e'
```

全连接层不做卷积扫描，而是把所有特征一次性综合起来，每个输出都看了全部输入，所以叫"全连接"。

### Q: 为什么需要两个全连接层？

一个全连接层只能学线性关系（加权求和是线性的）。加一个隐藏层并插入 ReLU，就能学非线性关系。

举例：判断字母 "b" 需要同时满足"左边有竖线 **且** 右边有圆圈"：

- 一层全连接：只能学"竖线权重 + 圆圈权重"，两个条件单独看，分不开
- 两层全连接 + ReLU：中间层能学会"竖线和圆圈**同时**出现时才激活"，组合判断

多一层就多一次组合 + 过滤，表达能力更强。但不是越多越好，太多容易过拟合。

## Keras vs TF1 原生 API

### Q: Keras 是什么？

Keras 是深度学习的高级 API，用来简化神经网络构建。TensorFlow 是底层引擎，Keras 是上层封装。

同一层卷积的写法对比：

**TF1 原生（~10 行）：**
```python
wc1 = tf.get_variable(name='wc1', shape=[3, 3, 1, 32], dtype=tf.float32,
                      initializer=tf.contrib.layers.xavier_initializer())
bc1 = tf.Variable(0.1 * tf.random_normal([32]))
conv1 = tf.nn.relu(tf.nn.bias_add(tf.nn.conv2d(x, wc1, strides=[1,1,1,1], padding='SAME'), bc1))
conv1 = tf.nn.max_pool(conv1, ksize=[1,2,2,1], strides=[1,2,2,1], padding='SAME')
conv1 = tf.nn.dropout(conv1, keep_prob)
```

**Keras（3 行）：**
```python
Conv2D(32, (3, 3), activation='relu', padding='same'),
MaxPooling2D((2, 2), padding='same'),
Dropout(0.25),
```

Keras 自动处理权重初始化、偏置、前向传播，不需要手动管理 Session 和 feed_dict。

## 一句话总结

**卷积层看图找特征（逐层从线条到笔画到字母），全连接层根据特征投票分类，偏置和 ReLU 控制激活门槛，池化精简信息，Dropout 防止过拟合。**
